# Affiliate renewal tiers — 21 October 2026 (#AFFILIATE-TIERS-1021)

Decision (Michele, 21/10/2026): commissions stay on BetRedge subscriptions only — no share of
partner/casino CPA or revenue share, no multi-level. Affiliates who bring more paying subscribers
earn a higher percentage on renewals.

## What changes

- `lib/affiliate/tiers.ts`: ladder parsed from `AFFILIATE_RENEWAL_TIERS` (`"<min>:<rate>,…"`),
  default `5:0.10,15:0.15`; `none` disables tiers. Malformed values fall back to the default.
- `decideCommission` (ledger): renewal rate = `tierFor(payingReferred, AFFILIATE_RENEWAL_RATE, ladder)`.
  First purchase stays at `AFFILIATE_FIRST_RATE` (20%). Tiers only ever raise the base rate.
- `payingReferred` = distinct referred users of the affiliate with at least one `first`/`renewal`
  row not `reversed`/`void` (shadow rows count only in shadow mode). Measured right before each
  commission is written, so the n-th paying referral raises the rate from the next payment on,
  for every renewal of that affiliate. The applied rate is already stored per row in
  `affiliate_commissions.rate`; the log line adds `rate=… paying=…`.
- `/api/affiliate/me` returns `tier` (level, rate, base/first rates, paying_referred, next step,
  ladder) from the same count; the panel shows it as "Il tuo livello / Your level".
- `/affiliates/terms` section 3 describes the tiers; page version `aff-2026-10-21-v2`.

## No migration

No schema change: the count is derived from `affiliate_commissions`. Rollback = revert the
deploy, or set `AFFILIATE_RENEWAL_TIERS=none` (base rate only, nothing else changes).

## Activation checklist (deploy-gate)

1. Merge + deploy.
2. Set `AFFILIATE_TERMS_VERSION=aff-2026-10-21-v2` on Vercel Production together with the deploy
   (enrollment records the version shown on the page). Existing affiliates keep their accepted
   version; tiers are an increase, allowed under section 8 of the terms.
3. Optional: `AFFILIATE_RENEWAL_TIERS` to change the ladder without a deploy.
4. Verify: `/api/affiliate/me` of an enrolled account shows `tier.ladder = [{5,0.10},{15,0.15}]`.
